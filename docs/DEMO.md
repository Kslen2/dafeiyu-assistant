# 大肥鱼助手 Demo

仓库里的网页应用自带一组完全虚构的演示数据。首次在一个全新的浏览器数据空间打开时，会直接看到聊天、饮食、饮水、睡眠、运动、消费、趋势和待办示例；不需要 API Key，也不会发送网络请求。

## 启动

在项目根目录运行：

```powershell
python -m http.server 4191 --directory .\dist
```

然后在浏览器访问 `http://127.0.0.1:4191/`。

## 建议的演示路径

1. 在“聊天”查看示例对话和快捷入口。
2. 打开“当天”，查看当天指标、时间轴、待办和记录卡的编辑/删除入口。
3. 打开“趋势”，切换周/月范围，查看睡眠、饮水、运动、饮食和净消费汇总。
4. 回到“聊天”，输入“喝水 250 毫升，坐公交花了 2 元”，验证一条消息可生成多条结构化记录。
5. 输入“上午十点快走 30 分钟”，验证明确时间会被保留。
6. 在操作结果卡中点击“撤销”，验证当天和趋势同步回退。
7. 输入“晚饭吃了一碗牛肉面”，在未配置 Key 时确认应用只提示缺少 AI 配置，不会伪造营养结果。

## 启用 AI 演示

进入“设置”，在本机填写自己的 DeepSeek API Key。Key 只保存在当前浏览器或 APK 的 IndexedDB 中，不在源码、Demo、备份或 GitHub 仓库里。

启用后可以演示：

- 餐食文字与照片的热量、蛋白质、碳水和脂肪估算；
- 团购券、退款、核销和口头纠错；
- 自由生活事件分类；
- 日、周、月总结和最多 5 条建议；
- 用自然语言修改助手的关注重点、目标、语气和回复长度。

## 重置

“设置”中的“清除所有本地数据”可恢复到初始演示状态。此操作会删除当前设备上的记录，正式使用前请先导出完整 JSON 备份。

## 已验证场景

1. 同一天确认两条饮食后正确累计：鸡肉米饭 565 kcal + 西瓜汁 90 kcal = 655 kcal；趋势同步为蛋白质 47g、碳水 84g、脂肪 12g。
2. 先说“吃了一包薯片”，再说“算一下热量”，能够承接上一条上下文并给出 405 kcal 估算。
3. 单独说“你好”会正常聊天，不会生成生活记录。
4. “公交 ¥1 + 饮水 250ml + 明天买菜待办”能在一条消息中拆成三类数据。
5. 裸输入“记录”只追问完整内容，不写入无意义笔记。
6. 非食物图片能够识别为非餐食，不再出现确认入库按钮。
7. 没有任何有效记录时，日总结显示“今日无记录”，不会虚构建议。
8. 周总结只读取最近 7 天；月总结读取最近 31 天，并能引用 20 天前的消费、睡眠和饮食记录。

## 测试中发现并修复

### 1. 饮食问题被误存为饮食记录

“我今天吃了什么？”原先会被 `吃了` 关键词误判为新的饮食记录。现在已将“吃了什么、吃啥、最近吃得怎么样、该吃什么”等问题路由到正常对话，并加入 5 个回归场景。

### 2. 助手违背长期偏好

闲聊时曾主动询问是否记录心情，并暗示可以按时间主动提醒。现在 system prompt 明确：不记录或追问体重、心情；应用只能保存待办，不能承诺主动通知。

### 3. 非食物图片仍可确认入库

AI 已判断图片不是餐食时，旧界面仍显示“确认并计入记录”。现在识图 JSON 增加 `is_food`，非餐食卡片只显示原因和“未计入饮食记录”。

### 4. 月总结上下文只有 7 天

现在周总结使用 7 天记录，月总结使用 31 天记录；总结请求不再附带无关闲聊历史，避免重复讨论旧餐食。
